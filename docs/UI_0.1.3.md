# 0.1.3 配置界面整理

设计北极星：打开就能改规则，改完立即保存。

这是 Android 原生设置工具，用户的主要任务是切换过滤模式与管理规则。沿用现有绿色图标的强调色、系统字体和原生开关，用总开关、模式、规则三个区域组织首页，不另做风格探索或引入图像素材。

## 操作与文案

- 移除复制备份、评论试算和首页“保存并应用”。
- 开关、黑白名单模式、规则启停直接自动保存；规则编辑点“完成”后自动保存应用。
- 新规则名称可不填，自动生成“规则 1”等唯一名称。
- 点规则打开编辑，右侧菜单提供编辑和删除。删除立即生效，底部提供撤销；下一次修改结束撤销机会，避免撤销覆盖新编辑。
- 将高级 JSON、大小写选项和帮助收进“更多”，不再占首页大块空间。
- 首页只留模式含义和自动保存反馈；条件组合说明放在编辑页与帮助。性别在规则摘要中显示“男 / 女 / 未知”。
- 白名单没有启用规则时提示会显示全部评论，而不仅仅检查列表是否为空。

## 自动保存

`SettingsRepository` 使用应用 Context 持有进程级 `AutoSaveQueue`，不持有 Activity。队列串行写入并合并尚未开始的中间状态，防止快速切换时旧配置覆盖新配置。完成提交后仍通过原有 `ConfigStore` 的 revision 与 Provider 通知同步到快手。

写入失败时保留当前输入与界面状态，底部显示“保存失败，点此重试”；不把失败状态显示为已保存。Activity 重建时继续使用同一队列，规则表单和高级编辑器的未完成输入通过 Bundle 恢复。

“已保存”表示配置已写入模块存储；已有快手评论列表仍需刷新，新加载的评论使用最新规则。

## 视觉与动效

- 浅底、白色分组、多级中性色；绿色用于主操作和选中状态，提供深色模式。
- 按钮、开关保留原生点击与滑动反馈；规则增删使用 160 ms 淡入；首次进入主操作区使用 180 ms 淡入。
- 尊重系统动画关闭设置；字号按系统字体缩放，主要按钮采用内容决定高度和最小触控尺寸。
- 添加按钮固定在页面底部，规则区域独立滚动。错误与撤销共用底部状态位置，避免重新加入一个常驻保存按钮。

## 验证与证据

真实配置界面运行于临时只读 Android 模拟器（API 37，393 × 851 dp），不使用真实用户设备或保留模拟器测试数据。过滤运行环境仍以用户 Android 16 / LSPosed 2.1.0 的已反馈结果为准。

证据目录：`docs/ui-0.1.3/`。`before.png` 是旧版基线，其他图片及交互记录来自新版真实 Android 界面。回归入口为 `scripts/ui_smoke.py`，只接受明确指定的 `emulator-*` 设备。

自动保存另有 6 项独立单元测试，覆盖快速连续操作、写入期间新编辑、失败后保留输入与重试、旧写入失败、非法配置和 Activity 取消订阅。视觉与 UX 走查记录及最终实测结果随同证据目录保存。

主代理已运行 `scripts/ui_smoke.py` 三轮：新增、编辑、删除、撤销、黑白名单切换、快速开关、进程重启读回均通过；另将临时模拟器模块的 SharedPreferences 目录设为不可写，确认界面保留输入并显示重试，恢复权限后重试保存及重启读回通过。记录在 `interaction-results.json`。

一轮独立存量视觉评审（`ui_visual_review`，不打分）确认主要信息层级、对齐和精简文案；指出浅底状态栏图标对比度不足。已在窗口重新获得焦点时依据日夜模式设置系统栏外观。未因空列表留白增加装饰内容。

主代理复核了修正后的浅色首页、深色首页、2 倍字体和 320 × 640 dp 窄屏表单：文字可读，主要按钮保持可见；长内容通过滚动访问。字号变化导致 Activity 重建时，未完成的规则名称仍保留。截图使用合成规则，未使用真实评论或账号数据。记录在 `layout-results.json`。

最终验证：47 项核心测试、7 项适配层测试通过；Debug APK 构建成功并通过签名校验，版本为 0.1.3 / versionCode 4；Lint 为 0 错误、2 条既有工具版本提示。

一轮独立轻量 UX 走查（`ux_final_review`，未提供原始任务、源码或预期路径）从真实空白配置首页自行选择添加关键词黑名单、开启过滤、查看说明、重启确认保存的路径，配置任务完成，未发现有证据支持的关键操作问题。未操作快手，所以没有将实际评论过滤视为本轮通过项。详见 [UX 报告](ui-0.1.3/ux-review/review.md)。
