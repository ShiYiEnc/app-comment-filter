## 0.1.2 升级复测

1. 覆盖安装新版 APK，保留规则；强制停止并重新打开快手。
2. 沿用之前会让评论区卡住的规则与视频。过滤后不足一屏时，应在本页完成后自动请求后续页。
3. 连续多页全被过滤时，最多自动补 5 页；若仍不足，应在评论列表底部显示“继续加载评论”按钮。点击后显示“加载中…”并禁用，后续再次达到上限时按钮恢复；不点击则停留在当前列表，不弹窗。
4. 重点测试完全空列表、日夜模式、快速双击、连续多轮点击，以及刷新/切排序导致的适配器重建。关闭评论区、切换视频、进入后台或关闭过滤开关后，不应遗留按钮或驱动旧视频加载。新增的 Fragment 生命周期 Hook 会移除按钮；插件热更新下的行为仍需确认。
5. 到真实末尾或网络失败时应停止；有原生重试入口时仍使用快手重试，不伪造 `hasMore` 或 cursor。

## 第一次测试

1. 确认设备为 Android 16，LSPosed 管理器显示版本 2.1.0；记录所使用的 LSPosed 分支/构建号。
2. 确认设备快手包名 `com.smile.gifmaker`，版本名 `14.9.20.50799`、versionCode `50799`。不适配快手极速版。
3. 安装工程生成的 `app-debug.apk`；打开模块，保持总开关关闭，创建规则并点“完成”，确保配置页可正常再次读取。
4. 在 LSPosed 启用模块，勾选快手；强制停止快手并重新启动。
5. 在 LSPosed 模块日志中搜索 `[KSFilter]`，先确认 `Adapter ready` 和 `Rules loaded, revision=...`。
6. 选择一个可重复打开的视频，记录几条主评论与对应回复，以其中一个具体短语建立黑名单规则。
7. 打开总开关，点击“保存规则”，回快手重新加载评论，检查目标主评论不可见，普通主评论保留。不要只检查已经缓存到界面的旧列表。

调试安装命令（设备已授权后自行执行）：

```powershell
adb install -r .\app\build\outputs\apk\debug\app-debug.apk
adb shell am force-stop com.smile.gifmaker
```

## 验收矩阵

| 场景 | 预期 |
| --- | --- |
| 总开关关闭 | 所有评论保留 |
| 黑名单关键词 | 命中的主评论隐藏 |
| 黑名单属地 | 按实际显示的属地匹配；其他属地保留 |
| 黑名单性别 | 仅服务端字段吻合时命中；缺失时为未知 |
| 黑名单时白名单中配置相反规则 | 白名单不参与判定 |
| 白名单模式 | 仅命中白名单的主评论保留；黑名单不参与判定 |
| 空/全部停用的白名单 | 保留全部主评论 |
| 同一规则中属地 + 关键词 | 同时满足才命中 |
| 两条不同规则 | 命中任一条即可 |
| UNKNOWN 性别 / 未知属地 | 只在明确配置未知条件时命中 |
| 主评论下的回复含被屏蔽关键词 | 主评论保留时，该回复仍显示 |
| 命中规则的主评论有回复 | 主评论及其回复入口一起不可见 |
| 特殊卡片、列表标题 | 不参与评论规则判定 |
| 加载下一页、切换排序 | 不崩溃；新组装的主评论按规则处理；分页继续 |
| 过滤后不足一屏 | 自动补页至按屏高估计的可见主评论目标；每轮最多补 5 页 |
| 后续一整页都被过滤 | 自动继续检查下一页，即使之前已加载很多主评论 |
| 5 次自动补页后仍不足 | 评论列表底部显示“继续加载评论”按钮，无需弹窗 |
| 点击底部按钮 | 显示“加载中…”并禁用，下一轮达到上限后可再次点击 |
| 关闭/隐藏评论面板或重建 adapter | 移除旧按钮；需要时只挂载到对应视频的新列表 |
| cursor 重复或 A→B→A | 停止自动请求，日志说明 repeated cursor |
| 加载中 | 不重复发起请求 |
| 宿主取消/刷新/释放或 Activity 暂停 | 取消排队补页并移除按钮 |
| 空列表时切后台再回到同一 Activity | 在会话仍有效时恢复未发出的补页或底部按钮，不重复消耗预算 |
| 切换模式/修改规则/关闭总开关 | 保存后刷新列表，检查结果变化及原评论恢复 |
| 升级快手到其他版本 | 输出不支持版本日志，过滤停用 |

## 日志判断

| 日志/现象 | 定位方向 |
| --- | --- |
| 完全没有 `[KSFilter]` | 模块未启用、作用域错误、快手进程未重启或框架未注入 |
| `Unsupported host version` | 设备 APK 与本次适配身份不一致 |
| `Adapter unavailable` | 类加载器/符号变化；提供异常类型和快手版本即可继续定位 |
| `Rules unavailable` | Provider 访问或配置编译失败；启动阶段保留全部，之后保留最后有效规则 |
| `Adapter ready` 但启用后没有 `List passes` | 可能没有进入 w1 路径、规则尚未加载或总开关关闭 |
| 有处理次数但始终隐藏 0 条 | 检查当前模式及启用的规则，再确认实际字段、主评论类型与实验分流 |
| 日志显示隐藏，但界面仍可见 | getter 可能被内联或展示使用另一条路径，需要运行证据 |
| `Response adapter failed` | 具体响应 getter 不符合预期，保留评论等待重新适配 |
| `Continue short filtered list via host pager` | 模块已通过宿主入口补充加载 |
| `Pagination stopped: repeated cursor` | 游标未前进或回环，已停止自动补页 |
| `Pagination continuation unavailable` | 分页符号/状态不符合预期，保留原生加载行为 |
| `Comment footer unavailable` | 未找到唯一且就绪的评论面板，或原生页脚结构不匹配；不回退到弹窗 |

首次反馈建议提供：LSPosed 分支/构建号、快手版本、`[KSFilter]` 相关日志，以及“预期隐藏/实际保留”的规则和现象。无需提供账号、Cookie 或完整评论接口响应。
