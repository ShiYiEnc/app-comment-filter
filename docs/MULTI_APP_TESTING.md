## 安装与配置

1. 覆盖安装本工程的 `app/build/outputs/apk/debug/comment-filter-0.2.0-debug.apk`，模块名称为“评论过滤”。
2. 在 LSPosed 启用模块，勾选要过滤的应用，然后强制停止并重新打开这些应用。
3. 打开模块，从顶部选择目标应用，设置规则、黑白名单模式和开关，点击“保存规则”。
4. 刷新或重新进入该应用评论区；已经展示的评论不主动重绘。分别配置普通哔哩哔哩和 HD。

只对 README 中的精确版本名和 versionCode 安装 Hook。版本不符时模块日志会显示 `Unsupported <package> version`；符号不符时显示 `adapter unavailable`，保留宿主原行为。

## 每个应用的真机检查

先用不同关键词（如每个应用不同的测试词）建立黑名单，确认跨应用不会串用。逐项确认：关闭时不隐藏、开启后关键词命中、IP 属地、未知属地、性别/未知性别、白名单的命中和未命中、空白名单保留全部、停用单条规则、修改后保存刷新、置顶、楼中楼、连续翻页、退出重进与快速切换内容。

小红书自模块 0.2.6 起移除性别过滤和资料查询：男女及未知性别条件全部暂停，混合规则仅按剩余属地和关键词匹配，纯性别白名单不造成评论全部消失。检查添加/编辑规则无性别选项、无资料开关，其他应用仍保留性别选项。还需检查隐藏主评论的关联回复、折叠、翻页和列表位置；投影后采用完整刷新保护差量索引。

快手保持原自动补页和继续加载按钮。其他新增应用只保留原生翻页，没有套用快手私有分页实现，需重点验证整页被过滤时能否继续加载。

独立回复详情、未知混排卡片、直播、电商和 Web/Hunter 页面不声明覆盖；哔哩哔哩的独立单条置顶入口详见分析记录。新适配是否在实际页面触发、热更新/实验分流是否改变路径，需要以上设备检查确认。
