# 更新记录

## 0.2.1（versionCode 9，2026-10-29）

- 小红书新增独立性别过滤开关，默认关闭，遵循手动保存；关闭时隐藏规则表单的性别项，保留并暂停已有性别条件，混合规则其余条件继续执行。
- 开启且当前模式存在有效性别条件时，通过原包已核对的用户资料服务异步加载作者性别，优先使用宿主已有资料预加载结果。按用户 ID 关联，0 男、1 女、2/其他值未知。
- 加载中的作者与未知性别分开处理；资料返回后从未过滤来源更新评论显示。关键词/属地独立黑名单不等待性别，关闭开关取消等待任务和旧代回调。
- 资料请求去重、并发/队列上限、缓存期限、请求间隔、独立超时与阻塞订阅工作池；自动重绘不重新发起已淘汰作者请求，避免长列表反复查询。
- 统一应用选择、规则编辑、高级配置和帮助弹窗样式，补充资料加载说明；改善保存后的刷新提示。
- 118 项单元测试、Debug 构建与 Lint 通过。API 37 模拟器检查开关显隐、保存恢复、规则条件保留、不同应用隔离、窄屏/大字号/深色弹窗。真实小红书资料请求及 Android 16 + LSPosed 宿主运行尚待真机确认。

## 0.2.0（versionCode 8）

- 增加哔哩哔哩 9.17.0、哔哩哔哩 HD 2.5.1、小红书 9.52.0、抖音 40.9.0 的原生主评论适配；各自校验包名、版本名和 versionCode。
- 模块更名“评论过滤”，保留原包名和安装兼容性。LSPosed 作用域和包可见性声明包含五款应用。
- 增加应用选择；分别保留开关、模式、规则、大小写选项、草稿和撤销状态。继续手动保存，只写入当前应用。
- 原快手配置惰性迁移，新应用默认关闭。独立配置文件、修订号、通知 URI 和 UID 访问校验防止串用规则。
- 哔哩哔哩在响应列表 getter 过滤；小红书在列表提交时投影并使用完整刷新保护 DiffUtil 索引；抖音在首次/后续请求分发时使用响应副本保留分页信息。
- 小红书该版本没有评论性别字段，统一按未知匹配并在规则表单提示。保留快手既有补页，其他应用保留原生分页。
- 小红书删除重建操作单独读取未过滤的备份列表，避免过滤投影回流到宿主状态；完整刷新遇到布局繁忙时有界重试。
- 85 项单元测试、Debug 构建和 Lint 通过；配置 UI 验收与新适配真机边界见 `MULTI_APP_TESTING.md` 和各应用 APK 分析记录。

## 0.1.6（versionCode 7）

- 取消自动保存；规则新增、编辑、删除、启停、总开关、模式及高级选项均只修改当前草稿，点击“保存规则”才写入并通知快手。
- 移除最底部状态文字。保存期间按钮显示“保存中…”，完成或失败用短暂提示反馈；失败可再次点击保存重试。

- 增加明确配置快照的手动保存测试，共 56 项测试。当前交互回归入口为 `scripts/manual_save_smoke.py`，历史自动保存脚本仅适用于 0.1.3–0.1.5。

## 0.1.1（versionCode 2）

修复目标：0.1.0 过滤后只剩少量主评论或完全为空，无法通过上滑触发快手下一页加载。

- 每次分页成功提交后，按可见主评论数量决定是否通过快手原有入口继续加载。
- 新页没有新增可见主评论时，即使已经加载过很多旧评论，也继续检查下一页。
- 每轮最多自动补 5 页；仍不足时显示“继续加载评论”，可继续下一轮或暂停。
- 保留宿主 cursor / hasMore / 加载中 / 登录限制；末尾、错误和重复游标停止续载，不伪造分页状态。
- 宿主取消、刷新或释放分页对象时取消本轮补页；Activity 切后台时暂停，恢复后重新安排尚未发出的动作。
- 不改变原有名单、字段或主评论过滤范围，覆盖安装可保留配置。

验证：41 项 core 测试和 7 项适配层测试通过，Debug 构建成功，Lint 无错误。新增真实分页 Hook、提示框及面板生命周期行为等待设备复测；同一 Activity 内面板关闭是否触发宿主取消事件属于重点验收项。
