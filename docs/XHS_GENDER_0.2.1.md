> 历史功能：小红书资料性别过滤已按用户要求在 0.2.6 删除；当前仅支持属地和关键词。见 [当前说明](FIXES_0.2.6.md)。

日期：2026-10-29（Asia/Shanghai）。目标仍是用户指定的小红书 9.52.0 / 9520807，原 APK 包清单 REA Evidence `ev_7d99df27aafc61a2daba462696de971348185e0656f48a4197df3039f84604a5`。接口、字段和资料性别值的静态依据见 [资料复核](XHS_GENDER_PROFILE_NOTES.md)，本次没有发起真实资料请求或读取用户账号数据。

## 使用行为

在首页选择“小红书”后，出现独立的“启用性别过滤”开关。开关默认关闭，和规则一起点击“保存规则”才持久化。原生评论模型无法直接读取性别，界面明确说明开启后需要额外加载作者资料；资料返回后自动更新已记录的评论列表。

- 关闭：添加和编辑规则不显示性别选项。已有性别数组不删除，列表显示暂停提示。纯性别规则暂停；关键词/属地与性别混合的规则只执行剩余条件。只有暂停性别规则的白名单视为无有效条件，显示全部评论。
- 开启：规则可选男、女、未知。只有总过滤开启且当前黑白名单模式中存在启用的性别条件时才排队加载资料。
- 资料尚未返回：不等同于未知，不让未知性别规则提前隐藏作者；黑名单仍执行不依赖性别的独立关键词/属地规则。白名单先保留可能命中的评论。
- 资料缺失/失败/超时：按未知处理，继续使用规则。取得的是用户资料中声明的性别，不推断真实身份。
- 其他四款应用不显示这个专属开关，仍直接读取其评论携带的性别。

配置可选布尔键为 `resolveProfileGender`，默认 false，schemaVersion 仍为 1。旧配置和其他应用原有的 evaluate 行为兼容。性别规则即使隐藏也保存在当前应用的配置中，重新开启后恢复。

## 请求与显示更新

`XiaohongshuGenderResolver` 在宿主进程内调用已核对的 `gn8.c.a.b(UserServices.class)` 和 `UserServices.getUserInfo(Map)`，参数包含目标 `user_id`；使用原宿主网络签名与响应流程，不打开资料页面，不给模块添加联网权限。可用时先检查 `f95.b` 的 `ProfilePreloadUserInfo`。只接受返回用户 ID 与请求完全一致的资料。

资料查询由独立工作池执行，与超时调度分离。最多 2 个活跃资料请求、128 个等待请求、512 条缓存，启动间隔至少 350ms，超时 10 秒；有效性别缓存 1 小时、明确未知 5 分钟、失败 1 分钟，队列过载短暂按未知回退。请求和结果仅保存在宿主进程内，关闭开关清空并取消旧任务。工作池也有有界队列，阻塞或忽略中断的订阅不会挤占超时线程。

宿主列表正常提交和保存规则变更可发起资料请求；资料完成触发的自动重算只读已完成缓存或既有请求，避免长列表超过缓存容量时循环查询。超过容量或被淘汰的作者会保守回到未知，下一次原生列表提交/规则保存可重试，不能保证所有作者都能获取资料。

显示层始终保留原始列表快照，按适配器弱引用隔离；即使第一次展示时开关关闭，也能在保存开启后从当前列表开始加载。资料结果重算不修改原评论模型、原始列表或分页字段。已有删除重建作用域保护和 DiffUtil 完整刷新保护继续保留。

## 弹窗方向与实现

沿用首页浅灰绿/森林绿、无衬线字、克制留白。弹窗采用 22dp 表面圆角、24dp 内容对齐、统一标题/应用上下文、10dp 输入和按钮圆角；按钮最小点击高度 48dp。主操作为实心强调色，取消为浅色表面。保留 Android 原生焦点、滚动和输入法行为，内容高度受当前可用视口约束，支持深色模式和大字号。

沿用原点击波纹、列表切换反馈，并加入尊重系统动画设置的 180ms 弹窗入场。没有制作风格对比页，因为用户要求沿用整体 UI。删去旧的“当前所有小红书性别只能未知”表单说明，替换为具体的加载与回退行为，没有增加常驻底部状态栏。

一轮隔离 UX 走查由 `/root/gender_ux_review` 执行，入口、观察和截图见 [评审记录](ui-0.2.1/ux-review/ux-review.md)。评审发现保存后的刷新步骤藏在帮助里，现将刷新提示合并到保存成功 Toast。主 Agent 另检查实际截图，修复原生按钮行裁掉顶部圆角的问题；不将截图存在等同于视觉验收。

## 验证与剩余范围

自动化验证包含规则开关语义、纯性别/混合规则、pending 与未知的区分、按 ID 关联、响应后重算和关闭恢复、去重、并发限制、超时/晚到响应、取消、错误/错用户返回、缓存期限、长列表重绘不重复请求及阻塞订阅与超时分离。构建命令仍为 README 中的 Gradle 四项任务。

模拟器脚本 `scripts/xhs_gender_ui_smoke.py` 检查开关显隐、原性别条件保留、手动保存和重启恢复、其他应用不受影响、白名单暂停提示、深色/窄屏/大字号/软键盘；截图和机器结果位于 `docs/ui-0.2.1/`。脚本隔离并恢复原配置、主题、字号、输入法与分辨率，不擦除 AVD。

尚未在 Android 16 + LSPosed 的实际小红书进程验证网络签名、服务端有效性别覆盖、登录状态/失败响应和自动重绘。模型与客户端代码支持该实现，不等同于真实请求已成功。真机应分别测试开关关闭无资料查询、开启后先显示再过滤、未知性别、翻页重复作者、请求失败/超时、保存关闭后恢复评论及不再产生旧结果。
