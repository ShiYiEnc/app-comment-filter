# 评论过滤

[下载最新版](https://github.com/ShiYiEnc/app-comment-filter/releases/latest) · [AGPL-3.0 许可证](LICENSE)

用于快手、哔哩哔哩、哔哩哔哩 HD、小红书和抖音的 LSPosed 评论过滤模块。支持按 IP 属地、评论关键词和用户性别设置黑名单或白名单，各应用单独保存配置。

当前版本：**0.2.7**。使用环境：**Android 16 + LSPosed 2.1.0**。

## 支持的应用

| 应用 | 适配参考版本 | IP 属地 | 关键词 | 性别 |
| --- | --- | --- | --- | --- |
| 快手 | 14.9.20.50799、14.9.30.50933 | ✓ | ✓ | ✓ |
| 哔哩哔哩 | 9.17.0 | ✓ | ✓ | ✓ |
| 哔哩哔哩 HD | 2.5.1 | ✓ | ✓ | ✓ |
| 小红书 | 9.52.0 | ✓ | ✓ | — |
| 抖音 | 40.9.0 | ✓ | ✓ | ✓ |

其他版本也会尝试加载，能否生效取决于应用的评论接口。直播、电商、网页评论及部分独立详情页不在支持范围内。

仅对主评论匹配规则，楼中楼回复不单独过滤。小红书隐藏主评论时，会一并移除可识别的对应回复及展开、收起、加载回复条目。

## 使用方法

1. 在 LSPosed 中启用“评论过滤”，勾选需要过滤的应用作用域，然后强制停止并重新打开这些应用。
2. 打开“评论过滤”，点击顶部应用名称，选择要配置的应用。
3. 选择“黑名单”或“白名单”，点击“添加规则”，填写条件后点击“完成”。
4. 打开“启用过滤”，点击“保存规则”，等待保存完成。
5. 回到对应应用，刷新或重新进入评论区。

修改开关、模式、规则或大小写选项后，都需要点击“保存规则”。保存只作用于当前选择的应用；哔哩哔哩和哔哩哔哩 HD 也需要分别配置。

切换应用会保留本次未保存的编辑，但不会自动保存。强制停止模块后，未保存的修改会丢失。

### 黑名单与白名单

| 模式 | 效果 |
| --- | --- |
| 黑名单 | 隐藏符合任意一条已启用规则的主评论 |
| 白名单 | 只保留符合任意一条已启用规则的主评论 |

两种模式各自保存规则，同一时间只执行选中的模式。首次使用时过滤默认关闭。白名单为空或所有规则均已停用时，保留全部评论。

### 填写规则

- **名称**：用于区分规则，可以留空。
- **IP 属地**：每行填写一个，例如“广东”“上海”。按属地名称匹配；勾选“包含未知属地”可匹配没有属地信息的评论。
- **评论关键词**：每行填写一个，正文中包含任意一个关键词即可匹配。默认忽略英文大小写，可在“更多 → 关键词忽略大小写”中调整。
- **用户性别**：可多选“男”“女”“未知”，以应用提供的用户性别为准。小红书不提供此项。

每条规则至少填写一类条件。未填写的条件不作限制；同一类填写多个值时，符合其中一个即可；同一条规则填写多类条件时，需要同时满足。

例如，在黑名单中设置：

| 规则 | 条件 | 效果 |
| --- | --- | --- |
| 推广 | 关键词分别填写“加群”“返现” | 隐藏正文包含“加群”或“返现”的主评论 |
| 指定属地的推广 | IP 属地填写“广东”，关键词填写“加群” | 只隐藏属地为广东且正文包含“加群”的主评论 |

如果希望“属地符合”或“关键词符合”就隐藏，应分别建立两条规则。

### 管理规则

点击已有规则可修改条件，通过规则开关可暂停或恢复该条规则。点击规则右侧的“⋮ → 删除”可删除规则。误删后可在“更多 → 撤销删除”中恢复，随后点击“保存规则”。

“更多 → 高级配置”可查看、复制和编辑当前应用的 JSON 配置。可参考 [规则示例](examples/)。编辑完成后仍需回到首页点击“保存规则”。

### 评论加载

过滤后评论较少或整页都被隐藏时，快手和抖音的 KMP 评论页支持自动继续加载，每轮最多补 5 页。

- 快手达到上限后，可点击评论列表底部的“继续加载评论”。
- 抖音达到上限后，可点击评论列表原有的底部加载入口继续查找。

规则较严格时，连续多页都可能没有符合条件的评论。

### 查看运行状态

在模块中选择应用，点击“运行状态”，可查看最近读取时间、读取和隐藏次数及异常信息。

- **已加载，等待评论**：模块已加载，尚未读到主评论；打开对应应用的评论区后再查看。
- **已读取评论**：模块已读到主评论并执行规则判断，是否隐藏取决于当前规则。

状态来自最近一次应用主进程的报告，不表示应用当前仍在运行。保存规则后页面没有变化时，先刷新或重新进入评论区；仍未生效时，检查 LSPosed 作用域、当前应用的过滤开关和运行状态。

## 隐私

模块无联网权限，不额外请求作者资料。运行状态只记录版本、时间、计数和异常类型，不保存评论正文或作者资料。
