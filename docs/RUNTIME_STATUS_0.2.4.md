# 0.2.4 版本兼容与运行诊断

2026-10-31。取消宿主 versionName / versionCode 的精确放行限制，表内版本仅作为静态适配基准。包名作用域和宿主主进程限制保持生效。每个适配器仍在安装前绑定关键类、方法和字段，检查已有的参数、返回类型与模型约束；不使用猜测的相似混淆类替代缺失符号。

## 状态的含义

| 界面状态 | 证据 |
| --- | --- |
| 未安装应用 | 模块查询不到目标包 |
| 尚无运行记录 | 没收到该应用的诊断报告；可能未启用模块、未勾选作用域或未启动应用 |
| 更新后等待验证 | 记录中的应用版本/模块版本与当前安装版本不同，不能沿用旧成功结论 |
| 正在检查适配 | 主进程进入模块，适配安装尚未结束 |
| 已加载，等待评论 | 必需 Hook 安装完成，未成功读取可处理的主评论 |
| 已读取评论 | 成功读取主评论并执行规则判断；无需隐藏任何条目 |
| 配置读取异常 | 读取规则失败，使用最后有效快照；首次失败时快照默认关闭 |
| 部分功能异常 | 评论模型读取/投影、快手补页，或启用中的小红书资料性别功能出现异常 |
| 适配失败 | 必需结构解析或 Hook 安装失败 |

记录属于最近一次宿主主进程，不是实时进程存活检测。详情显示当前版本、静态基准、保存的过滤开关、记录版本、进程开始时间、最近报告/成功读取时间，以及聚合读取和隐藏次数。计数包含重复 getter、重复列表处理及小红书重新投影；隐藏次数包含随主评论移除的附属条目，不表示独立作者数或去重后的屏幕评论数。

每次主进程启动创建新会话，清空上个会话的成功/故障证据。运行读取故障、补页故障在本会话保留；配置恢复后清除配置异常，小红书资料请求成功或关闭相关性别功能后清除资料异常。资料接口缺失只影响可选的性别功能；评论文本/属地必需字段仍须能解析。资料请求失败、超时和返回作者不匹配均记录资料异常，服务正常返回未填写性别不算故障。

## 上报与提示

- `FilterDiagnostics` 在过滤时只汇总读取数、隐藏数和异常，不保留评论对象、正文、作者 ID 或资料。
- `HookStatus` 在工作线程合并上报，正常批次约 2 秒，新故障尽快上报。回调不执行 Binder / JSON / 磁盘写入。
- `ConfigProvider.call("reportStatus", 包名, Bundle)` 按 Binder UID 校验；只允许模块 UID 或对应宿主 UID 上报该宿主状态，其他宿主/普通 shell 不能代报。规则查询权限保持原有边界，规则的 insert/update/delete 仍禁止。
- `RuntimeStatusStore` 独立保存诊断，不改动规则；校验消息大小、字段、错误类型和时间，拒绝较旧会话覆盖新报告。提醒按当前宿主版本和模块版本，分别对安装、运行、配置、资料、补页类别去重，并持久保存。
- 发现新故障后尝试显示宿主 Toast；一个宿主进程最多弹出一次。若诊断通道本身不可用，回退为进程内一次提醒和 LSPosed 日志。Android 可能限制 Toast，模块状态入口提供持久可查的记录。

## 检测边界

空列表、装饰条目、子评论、关闭过滤及未命中规则都不会据此判为失效。完全绕开旧 Hook 的新路径不会产生回调，不能仅靠超时判断为故障；进入有主评论的评论区后仍无读取记录，应检查作用域并人工核对新版本。结构签名相同但字段含义变化、宿主热更新，以及过滤结果是否最终被新 UI 使用，也无法完全自动证明。取消版本限制不等于自动适配所有新版本。
